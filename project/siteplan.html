3DPrints Site Plan

Site Name

3DPrints is the name I chose for my website. I chose this name because it is simple and clearly shows that the site is about finding 3D print ideas.

Site Purpose

3DPrints will help users search for different 3D print ideas. Users can search words like toy, desk, gift, tool, or home, and the site will show ideas that match.

The print ideas will come from a JSON file that I create. Each idea will include information like the name, category, difficulty, material, estimated print time, and a link to the print page.

Scenarios

  • What are some simple 3D print ideas I can make?
  • Can I search for 3D print ideas by keywords like toy, gift, or tool?
  • Where can I find a link to the original 3D print idea?

Color Schema

The website will use the following colors:

  • Dark Navy
    Primary -- used for headings, navigation, and footer areas.
  • Teal
    Accent -- used for buttons, links, and highlights.
  • Light Gray
    Background -- used for page backgrounds, sections, and cards.

Typography

Montserrat will be used for headings and the site title.

Open Sans will be used for body text, cards, and buttons.
